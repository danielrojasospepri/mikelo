🚀 FLUJO RÁPIDO - DESARROLLO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Crear rama feature
   $ git checkout -b feature/nombre-corto

2. Editar archivos
   $ code archivo.php
   $ ... cambios ...

3. Commit local
   $ git add .
   $ git commit -m "mensaje descriptivo"

4. Subir rama
   $ git push -u origin feature/nombre-corto

5. Mergear a main (cuando esté listo)
   $ git checkout main
   $ git pull origin main
   $ git merge feature/nombre-corto
   $ git push origin main

6. Crear tag de hito
   $ git tag -a v1.X-hito -m "descripción"
   $ git push origin v1.X-hito

7. Limpiar rama local
   $ git branch -d feature/nombre-corto
   $ git push origin --delete feature/nombre-corto


⚠️ EMERGENCIA - RECUPERACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Si necesitas volver a Fase 1 completa:
  $ git reset --hard v1.0-fase1
  $ git push origin main --force

  Si cometiste push incorrecto:
  $ git revert COMMIT_HASH
  $ git push origin main

  Si necesitas revertir último commit:
  $ git reset --soft HEAD~1
  (mantiene cambios para reeditar)


📋 CHECKLIST PRE-MERGEAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Antes de hacer merge a main:

  ☐ Tests locales pasados
  ☐ Código PHP sin sintaxis errors: php -l archivo.php
  ☐ Sin conflictos con main
  ☐ Commits con mensajes descriptivos
  ☐ Revisó cambios: git diff main
  ☐ Backup BD si hace falta: mysqldump
