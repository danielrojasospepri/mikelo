Introducción al sistema

Conceptos generales y navegación

¿Qué es J.A.R.V.I.S.?

J.A.R.V.I.S. es el sistema de gestión de inventario y logística de Mikelo. Centraliza el control del depósito, los envíos a sucursales y la gestión de pedidos, permitiendo trazabilidad completa de cada producto desde el ingreso al depósito hasta la entrega en cada franquicia.

Iniciar sesión

Para acceder al sistema se requiere usuario y contraseña asignados por el administrador.

  1. Ingresar a la URL del sistema.
  2. Completar los campos Usuario y Contraseña.
  3. Hacer clic en Ingresar al Sistema.
  4. El sistema redirige automáticamente al módulo correspondiente según el perfil del usuario.
Los usuarios de planta son redirigidos al Panel Principal. Los usuarios de sucursal son redirigidos a Mis Pedidos.

Módulos de Sucursal

Funciones disponibles para el personal de franquicia

Mi Stock

Descripción: Visualiza el inventario actual de la sucursal. Muestra cada producto con su código, descripción y cantidad disponible en el local.

¿Para qué se usa? Para conocer el estado actual del stock antes de realizar un pedido, o para verificar que un envío fue recibido correctamente.

  1. Acceder desde el menú lateral Mi Stock.
  2. La tabla se carga automáticamente con el stock de la sucursal asignada al usuario.
  3. Se pueden filtrar productos por nombre o código usando el campo de búsqueda.
El stock se actualiza automáticamente al confirmar una recepción o registrar una baja.
Captura de pantalla: Stock Sucursal Reemplazar con imagen real: screenshot_stock_sucursal.png

Mis Pedidos

Descripción: Permite crear solicitudes de productos al depósito central. Los pedidos quedan en estado SOLICITADO hasta que planta los procesa y genera un envío.

¿Para qué se usa? Para solicitar reposición de stock cuando los niveles están bajos o se anticipa alta demanda.

Crear un pedido nuevo:
  1. Hacer clic en Nuevo Pedido.
  2. Seleccionar los productos y las cantidades requeridas. Se puede escanear el código de barras de cada producto.
  3. Confirmar con Enviar Pedido.
  4. El pedido aparecerá en la lista con estado SOLICITADO.
Estados posibles de un pedido:
SOLICITADOEnviado, esperando respuesta de planta
ENVIADOPlanta despachó el envío
RECIBIDOConfirmado en recepción
CANCELADOPedido cancelado
Captura de pantalla: Lista de pedidos y modal de nuevo pedido Reemplazar con imagen real: screenshot_pedidos.png

Recepciones

Descripción: Permite confirmar la recepción de los envíos despachados desde el depósito. Al confirmar, el stock de la sucursal se actualiza automáticamente.

¿Para qué se usa? Para registrar formalmente que la mercadería llegó al local, indicando las cantidades reales recibidas (que pueden diferir de lo enviado).

  1. Acceder a Recepciones desde el menú.
  2. En la pestaña Envíos Pendientes aparecen los envíos que aún no fueron confirmados.
  3. Hacer clic en Recibir en el envío correspondiente.
  4. Verificar cada ítem: indicar la cantidad realmente recibida (no modificar si coincide).
  5. Opcionalmente agregar observaciones.
  6. Confirmar con Confirmar Recepción.
Si hay diferencia entre lo enviado y lo recibido, registrar la cantidad real. El sistema guarda la diferencia para el seguimiento.
Captura de pantalla: Recepciones - envíos pendientes y confirmación Reemplazar con imagen real: screenshot_recepciones.png

Carga Inicial de Stock

Descripción: Permite registrar el inventario inicial de una sucursal cuando comienza a operar, o corregir el stock en caso de un inventario físico. Solo disponible para el perfil Franquicia Admin.

¿Para qué se usa? Para cargar el stock real existente en el local cuando se da de alta una sucursal, o después de realizar un conteo físico que detectó diferencias con el sistema.

  1. Acceder a Carga de Stock Inicial desde el menú lateral.
  2. Seleccionar el producto (búsqueda o escáner de código de barras).
  3. Ingresar la cantidad real existente en el local.
  4. Repetir para cada producto presente en la sucursal.
  5. Confirmar. El sistema establece esas cantidades como punto de partida del inventario.
Usar esta función solo cuando el stock en el sistema no refleja la realidad del local. Para movimientos normales usar Baja de Stock o Recepciones.
Captura de pantalla: Carga Inicial de Stock Reemplazar con imagen real: screenshot_carga_inicial.png

Stock Mínimo

Descripción: Define el umbral de alerta de stock para cada producto de la sucursal. Cuando el stock cae por debajo de ese valor, el producto aparece marcado como faltante para facilitar la planificación de pedidos. Solo disponible para el perfil Franquicia Admin.

¿Para qué se usa? Para recibir alertas cuando un producto está por agotarse, y así generar el pedido de reposición con anticipación.

  1. Acceder a Stock Mínimo desde el menú lateral.
  2. Buscar el producto a configurar.
  3. Ingresar el valor de stock mínimo (cantidad que dispara la alerta) y, opcionalmente, el stock óptimo (cantidad ideal a pedir para llegar).
  4. Guardar. El cambio tiene efecto inmediato.
Configurar el stock mínimo considerando el tiempo que tarda el pedido en llegar (planta procesa el pedido y genera el envío). Así el producto nunca se agota.
Captura de pantalla: Configuración de Stock Mínimo Reemplazar con imagen real: screenshot_stock_minimo.png

Baja de Stock

Descripción: Registra consumo, pérdida o cualquier egreso de productos del stock de la sucursal que no corresponda a una venta registrada en otro sistema.

¿Para qué se usa? Para mantener el inventario actualizado cuando hay productos vencidos, rotos, consumidos en el local o devoluciones.

  1. Seleccionar el producto (por búsqueda o escáner).
  2. Ingresar la cantidad a dar de baja.
  3. Seleccionar el motivo de baja.
  4. Confirmar la operación.
Esta operación no tiene marcha atrás. Verificar cantidades antes de confirmar.

Módulos de Planta / Depósito

Funciones disponibles para el personal del depósito central

Panel Producción

Descripción: Vista centralizada de los pedidos pendientes recibidos de las sucursales. Permite generar envíos en respuesta a cada pedido.

¿Para qué se usa? Es el módulo principal del operador de depósito. Desde aquí se controla el flujo de pedidos y despachos.

  1. Al ingresar se listan los pedidos con estado SOLICITADO.
  2. Hacer clic en un pedido para ver su detalle (productos, cantidades, sucursal).
  3. Verificar el stock disponible para cada ítem (se muestra en verde si hay suficiente, en rojo si no).
  4. Ajustar cantidades si el stock no alcanza para el total solicitado.
  5. Hacer clic en Generar Envío para despachar.
  6. El pedido pasa a ENVIADO y se crea el movimiento de stock correspondiente.
Captura de pantalla: Panel Producción - lista de pedidos y detalle Reemplazar con imagen real: screenshot_panel_produccion.png

Panel Faltantes

Descripción: Muestra los productos cuyo stock en el depósito está por debajo del mínimo configurado. Sirve de alerta para planificar la producción.

  1. Acceder a Panel Faltantes.
  2. La lista muestra producto, stock actual, stock mínimo y la diferencia.
  3. Coordinar con producción para reponer los productos críticos.
Los umbrales de stock mínimo del depósito se configuran directamente en la base de datos. El Stock Mínimo de cada sucursal lo configura el Franquicia Admin desde su menú.
Captura de pantalla: Panel Faltantes Reemplazar con imagen real: screenshot_panel_faltantes.png

Alta en Depósito

Descripción: Registra el ingreso de productos al depósito central. Soporta carga mediante escáner de código de barras o ingreso manual.

Formatos de código de barras admitidos:

TipoFormatoEjemplo
Por unidades20 + PPPPP + CCCCC2000123 00050 → 50 unidades del producto 123
Por peso21 + PPPPP + PPPPP2100123 01500 → 1.5 kg del producto 123
  1. Activar el escáner o buscar el producto manualmente.
  2. Ingresar la cantidad o escanear el código.
  3. Opcionalmente asignar un contenedor (ej: bandeja, caja).
  4. Confirmar la carga. El stock del depósito se actualiza de inmediato.
Captura de pantalla: Alta en Depósito con escáner activo Reemplazar con imagen real: screenshot_alta_deposito.png

Envíos

Descripción: Listado histórico de todos los envíos realizados desde el depósito a las sucursales. Permite crear envíos manuales (sin pedido previo) y consultar el estado de cada despacho.

  1. Acceder a Envíos desde el menú.
  2. Para crear un envío manual: clic en Nuevo Envío, seleccionar sucursal de destino, agregar productos y cantidades.
  3. Confirmar. El envío queda en estado ENVIADO y se descuenta del stock del depósito.
Los envíos generados desde el Panel Producción (en respuesta a un pedido) también aparecen aquí.
Captura de pantalla: Lista de envíos Reemplazar con imagen real: screenshot_envios.png

Movimientos

Descripción: Historial completo de todos los movimientos de inventario del depósito: altas, envíos, bajas y ajustes. Cada registro es trazable con fecha, usuario y productos involucrados.

Captura de pantalla: Historial de movimientos Reemplazar con imagen real: screenshot_movimientos.png

Productos / Familias

Descripción: ABM (Alta, Baja, Modificación) del catálogo de productos y sus familias (categorías). Disponible únicamente para Planta Jefe y Administrador.

¿Para qué se usa? Para incorporar productos nuevos al sistema, actualizar datos (descripción, código, peso) o dar de baja productos que ya no se fabrican.

Gestión de Productos:
  1. Acceder a Productos / Familias desde el menú lateral.
  2. Para agregar: clic en Nuevo Producto, completar código, descripción, familia y peso unitario.
  3. Para modificar: clic en el ícono de edición () en la fila del producto.
  4. Para dar de baja: clic en el ícono de eliminar (). Solo se puede eliminar si el producto no tiene movimientos asociados.
Gestión de Familias:
  1. Desde la misma pantalla, acceder a la pestaña Familias.
  2. Agregar o renombrar familias según sea necesario.
  3. Las familias se usan para filtrar y agrupar productos en todo el sistema.
El código de producto es el utilizado en los códigos de barras. No se puede cambiar si el producto ya tiene movimientos registrados.
Captura de pantalla: ABM Productos y Familias Reemplazar con imagen real: screenshot_productos_abm.png

Stock Depósito

Descripción: Consulta en tiempo real del inventario existente en el depósito central. Permite ver el stock disponible para cada producto, con filtros por nombre o código.

  1. Acceder a Stock Depósito.
  2. La tabla muestra todos los productos con su stock actual.
  3. Los productos en rojo tienen stock por debajo del mínimo.
  4. Se puede exportar el listado para su uso externo.

Módulos de Administración

Funciones exclusivas del perfil Administrador

Gestión de Usuarios

Descripción: ABM completo de usuarios del sistema. Permite dar de alta nuevos usuarios, asignarles rol y sucursal, y activar o desactivar cuentas existentes.

Perfiles disponibles:
  • Admin (nivel 10): Acceso total al sistema.
  • Planta Jefe (nivel 20): Depósito + visualización de sucursales.
  • Planta Operario (nivel 25): Operaciones de depósito.
  • Franquicia Admin (nivel 30): Gestión completa de una sucursal.
  • Franquicia Empleado (nivel 40): Operaciones básicas de sucursal.
  1. Clic en Nuevo Usuario.
  2. Completar: nombre de usuario, nombre completo, contraseña y rol.
  3. Para perfiles de franquicia: asignar la sucursal correspondiente.
  4. Guardar. El usuario puede iniciar sesión de inmediato.
Solo el Administrador puede crear, modificar o eliminar usuarios. Esta pantalla no es visible para ningún otro perfil.
Captura de pantalla: Gestión de Usuarios Reemplazar con imagen real: screenshot_usuarios.png

Sucursales

Descripción: Gestión del catálogo de sucursales/franquicias. Permite dar de alta nuevas ubicaciones, modificar datos y desactivar sucursales que cerraron.

  1. Acceder a Sucursales desde el menú de Administración.
  2. Para agregar: clic en Nueva Sucursal, completar nombre y tipo (propia o franquicia).
  3. Una vez creada la sucursal, asignar los usuarios correspondientes desde Gestión de Usuarios.
Los envíos del depósito solo pueden dirigirse a sucursales activas. Desactivar una sucursal no elimina su historial.
