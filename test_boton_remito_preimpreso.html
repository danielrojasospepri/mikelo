✅ Corrección: Botón Remito Preimpreso en Modal de Detalle

📋 Resumen del Problema

Error reportado: El botón "Remito Preimpreso" dentro del modal de detalle de envío no funcionaba.

Causa raíz:

  • El event listener se agregó en js/envios.js
  • Pero envios.html carga js/envios_nuevo.js
  • El botón nunca se registró en el archivo correcto

🔧 Cambios Aplicados

Archivo Cambio Línea
js/envios_nuevo.js Agregado event listener $('#btnRemitoPreimpresoModal').click() ~110
envios.html Actualizado número de versión del script a ?v=20251020_1630 356
envios.html Botón HTML id="btnRemitoPreimpresoModal" ya existía 339

💻 Código Agregado

Ubicación: js/envios_nuevo.js (línea ~110)

// Botón remito preimpreso en modal $('#btnRemitoPreimpresoModal').click(function() { if (window.envioSeleccionadoId) { exportarRemitoPreimpreso(window.envioSeleccionadoId); } else { Swal.fire('Error', 'No hay envío seleccionado', 'error'); } });

✅ Procedimiento de Prueba

  • Paso 1: Abrir envios.html en el navegador
  • Paso 2: Hacer clic en cualquier fila de la tabla de envíos (se abre el modal)
  • Paso 3: En el footer del modal, verificar que aparezcan estos botones:
    🖨️ Imprimir Remito 🖨️ Remito Preimpreso
  • Paso 4: Hacer clic en "Remito Preimpreso" (botón amarillo)
  • Paso 5: Verificar que:
    • ✓ Aparece mensaje "Generando remito preimpreso..."
    • ✓ Se abre nueva pestaña con el PDF
    • ✓ Aparece mensaje de confirmación

⚠️ Importante: Si usas Chrome/Edge, asegúrate de que el bloqueador de pop-ups esté deshabilitado para localhost.

🎯 Verificación Rápida en Consola del Navegador

Abre la consola del navegador (F12) y ejecuta estos comandos para verificar:

// 1. Verificar que el botón existe en el DOM console.log('Botón existe:', $('#btnRemitoPreimpresoModal').length > 0); // 2. Verificar que la función está disponible console.log('Función disponible:', typeof window.exportarRemitoPreimpreso); // 3. Simular selección de envío y ejecutar función window.envioSeleccionadoId = 1; // Cambiar por ID real window.exportarRemitoPreimpreso(1); // Debería abrir PDF

El botón no responde al clic Caché del navegador Presiona Ctrl + F5 para forzar recarga (el ?v=20251020_1630 debería evitarlo)
